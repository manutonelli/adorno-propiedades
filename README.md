# Adorno Propiedades

Preview responsive de una web inmobiliaria, construida con HTML, CSS y JavaScript. Incluye filtros, catálogo urbano/rural y fichas de propiedades.

## Abrir localmente

Abrir `index.html` en el navegador. No requiere instalación ni compilación. Montserrat se carga desde Google Fonts.

## Publicar con GitHub Pages

En Settings → Pages, seleccionar Deploy from a branch, rama `main`, carpeta `/ (root)` y guardar.

## Contenido de demostración

Propiedades, precios, ubicaciones y características ficticios. Los botones de consulta muestran una demostración y no envían mensajes. El panel administrador y la persistencia se implementarán en una etapa posterior.

Las imágenes de inmuebles son ilustrativas de Unsplash y deben reemplazarse por fotografías del cliente antes del lanzamiento definitivo. Logo aportado por el cliente. No se concede una licencia de uso del logo por publicar este repositorio.
